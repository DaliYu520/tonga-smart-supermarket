🧠 AI 老板助手

第一版先把“问问题 → 给出可执行建议”的入口和数据边界定下来。

今天可以问

“今天卖了多少钱？”

销售额、订单数、客单价。

“什么快没货了？”

库存 + 销售速度 + 安全库存。

“这周采购什么？”

生成采购草稿，不直接下单。

“给我做一个促销。”

生成商品和文案草稿。

AI安全边界

价格修改、退款、采购下单、库存调整等敏感动作必须确认，并记录操作人和时间。AI只提供建议，不直接绕过权限。

🔭 未来能力预留

现在不做、不增加成本，只保留系统接口和数据结构。

🤖 AI视觉收银

摄像头识别商品和数量 → 商品库取价 → 自动购物车 → 客户确认 → 支付。

🏪 无人超市

入口 → 购物 → 视觉/购物车 → 自动结算 → 支付 → 出口控制。

📷 AI防损

异常事件检测、人工复核；不把AI识别直接当作“偷盗结论”。

🏬 多门店 / 多商户

平台 → 商户 → 门店/仓库，第二家店通过配置复制，不重写核心系统。

V1 是第一版可操作原型。演示数据不是生产数据；真实数据库、支付、账号权限、AI接口和现场设备需要下一阶段接入。
